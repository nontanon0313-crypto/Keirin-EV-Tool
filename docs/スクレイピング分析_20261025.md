# スクレイピング処理 分析 2026-10-25

## 現行フロー
- make_joblist.py: joblist.txt 生成（日付×場×1〜12R）
- auto_fetch.py: joblist.txt を読み、1レースずつ subprocess で run_keirin.py を呼ぶ
- run_keirin.py: scrape_one_race() で oddspark から取得、JSON に保存
- run_full_pipeline.py: JSON を DB に投入

## 速度パラメータ（auto_fetch.py）
- SLEEP_BETWEEN = 1秒（1レース完了後の待機）
- SLEEP_RESTART = 5秒（全ジョブ1周後の待機）
- RACE_TIMEOUT = 300秒（1レース最大5分）
- 並列処理: なし（完全逐次）
- is_done()判定: scraped_at存在 + ridersがlist型
