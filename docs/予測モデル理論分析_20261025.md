# 予測モデル理論分析 2026-10-25

## ユーザー指摘（要検証）
1. AI推定値（ai_win_prob）はDB保存。予想と投票を分離するため
2. 各選手の1着確率をベースにしていいのか根拠が不明

## 現行モデルの構造（ソース確認済み）
- 入力: blended_win_prob（ai_win_prob と app_win_rate の合成）
- 1着確率補正: RACE_SCORE_BAND_FACTORS（105-110帯で1.4354倍）
- 3連単確率: harville_prob（1着確率を出発点に独立性仮定で2着・3着導出）
- ライン補正: SAME_LINE_BOOST=1.0（本番無効）
- キャリブレーション: 投票プランでは不使用

## ハービル法の理論的限界
- 前提: 1着確率から2着以下を「残りの再配分」と仮定（IIA仮定）
- 競輪はライン連動が存在。先行1着→同ライン番手2着が起きやすい
- ハービル法はこのライン連動を表現できない
- 1着確率の精度が高くても、独立性仮定が崩れれば3連単の精度は低い

## 検証設計
- 検証A: 1着確率のブライアスコア（blended_win_prob vs 実績1着）
- 検証B: 3連単確率のブライアスコア（ハービル法210通り vs 実績3連単）
- 検証C: ライン連動の実測（同ライン2着進出率、ハービル予測 vs 実績）

## ユーザー実践知見（2026-10-25追加）
「実践では3連単の順序まで当てなければならず、
2選手は当たるが順序が不一致で外れるケースが多かった」

## 理論的解釈
- 組み合わせ選定精度はあるが、順序推定精度が低い
- 原因候補1: ハービル法のIIA仮定の破綻（ライン連動を無視）
- 原因候補2: 1着確率自体の誤差
- 検証Dで切り分け可能

## 検証D: 順序精度の分離
1. 3連複（順不同）の予測確率と実績のブライアスコア
2. 3連単（順序あり）の予測確率と実績のブライアスコア
3. 両者の差 = 順序推定の誤差

### 解釈
- 3連複精度が高く3連単精度が低い → 順序推定が問題（IIA仮定の破綻）
- 両方低い → 1着確率自体が問題
- 両方高い → 問題なし（今回のケースではない）

## ユーザー指摘（2026-10-25追加）
「過去の勝率は選手情報の1要素でしかない。競走得点と同列にあるべき」

## 理論的含意
- 1着確率を単一要素（勝率のみ、競走得点のみ）で推定するのは不適切
- 複数要素（競走得点・勝率・2連対率・3連対率・脚質・ライン等）を統合すべき
- 各要素の寄与度は実測でしか分からない
- 段階的に要素を追加し、ブライアスコアで寄与を測る（アブレーション実験）

## アブレーション設計（1着確率の要素統合）
| 段階 | 入力要素 | 期待される効果 |
|---|---|---|
| 1 | 競走得点のみ（ソフトマックス） | 能力ベースの基準線 |
| 2 | + 勝率 | 直近の1着率を反映 |
| 3 | + 2連対率・3連対率 | 安定性を反映 |
| 4 | + 脚質・ライン | 展開・連動を反映 |

各段階でブライアスコアを測り、寄与度を確定する。
寄与が負の要素は除外する。

### 結果の理論的評価
- 3指標とも β=0.15〜0.20 で最小 → 競走得点の最適温度が存在する
- 1着BS: 均等予測0.1224 → 最良0.1120（8.5%改善）。競走得点は1着確率に効く
- 3連単BS: 均等予測0.004739 → 最良0.004705（0.7%改善）。ほぼ均等と同じ
- 3連単対数損失: 4.79〜9.01。モデルの識別力は限定的

### 重要な発見
1着確率の改善（8.5%）に対し、3連単確率の改善（0.7%）が極端に小さい。
1着確率の情報が3連単に伝わっていない。
これはハービル法のIIA仮定の破綻を数値で示す最初の証拠。
ユーザーの「順序不一致」の体感と整合する。

- 過学習防止: 時系列分割、交差検証、特徴数×10以上のサンプル
