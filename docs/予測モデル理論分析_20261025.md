# 予測モデル理論分析 2026-10-25

## ユーザー指摘（要検証）
1. AI推定値（ai_win_prob）はDB保存。予想と投票を分離するため
2. 各選手の1着確率をベースにしていいのか根拠が不明

## 現行モデルの構造（ソース確認済み）
- 入力: blended_win_prob（ai_win_prob と app_win_rate の合成）
- 1着確率補正: RACE_SCORE_BAND_FACTORS（105-110帯で1.4354倍）
- 3連単確率: harville_prob（1着確率を出発点に独立性仮定で2着・3着導出）
- ライン補正: SAME_LINE_BOOST=1.0（本番無効）
- キャリブレーション: 投票プランでは不使用

## ハービル法の理論的限界
- 前提: 1着確率から2着以下を「残りの再配分」と仮定（IIA仮定）
- 競輪はライン連動が存在。先行1着→同ライン番手2着が起きやすい
- ハービル法はこのライン連動を表現できない
- 1着確率の精度が高くても、独立性仮定が崩れれば3連単の精度は低い

## 検証設計
- 検証A: 1着確率のブライアスコア（blended_win_prob vs 実績1着）
- 検証B: 3連単確率のブライアスコア（ハービル法210通り vs 実績3連単）
- 検証C: ライン連動の実測（同ライン2着進出率、ハービル予測 vs 実績）

## データソース
| データ | 所在 | 制約 |

| ai_win_prob | DB entries | Grok事故で欠損レースあり |

- 検証は「DBに生きているレース」だけで可能
- 新規レース（2026-10-20以降）は ai_win_prob 未生成
