# 予測モデル理論分析 2026-10-25

## ユーザー指摘（要検証）
1. AI推定値（ai_win_prob）はDB保存。予想と投票を分離するため
2. 各選手の1着確率をベースにしていいのか根拠が不明

## 現行モデルの構造（ソース確認済み）
- 入力: blended_win_prob（ai_win_prob と app_win_rate の合成）
- 1着確率補正: RACE_SCORE_BAND_FACTORS（105-110帯で1.4354倍）
- 3連単確率: harville_prob（1着確率を出発点に独立性仮定で2着・3着導出）
- ライン補正: SAME_LINE_BOOST=1.0（本番無効）
- キャリブレーション: 投票プランでは不使用

## ハービル法の理論的限界
- 前提: 1着確率から2着以下を「残りの再配分」と仮定（IIA仮定）
- 競輪はライン連動が存在。先行1着→同ライン番手2着が起きやすい
- ハービル法はこのライン連動を表現できない
- 1着確率の精度が高くても、独立性仮定が崩れれば3連単の精度は低い

## 検証設計
- 検証A: 1着確率のブライアスコア（blended_win_prob vs 実績1着）
- 検証B: 3連単確率のブライアスコア（ハービル法210通り vs 実績3連単）
- 検証C: ライン連動の実測（同ライン2着進出率、ハービル予測 vs 実績）

## データソース
| データ | 所在 | 制約 |

- 新規レース（2026-10-20以降）は ai_win_prob 未生成

## ユーザー実践知見（2026-10-25追加）
「実践では3連単の順序まで当てなければならず、
2選手は当たるが順序が不一致で外れるケースが多かった」

## 理論的解釈
- 組み合わせ選定精度はあるが、順序推定精度が低い
- 原因候補1: ハービル法のIIA仮定の破綻（ライン連動を無視）
- 原因候補2: 1着確率自体の誤差
- 検証Dで切り分け可能

## 検証D: 順序精度の分離
1. 3連複（順不同）の予測確率と実績のブライアスコア
2. 3連単（順序あり）の予測確率と実績のブライアスコア
3. 両者の差 = 順序推定の誤差

### 解釈
- 3連複精度が高く3連単精度が低い → 順序推定が問題（IIA仮定の破綻）
- 両方低い → 1着確率自体が問題
- 両方高い → 問題なし（今回のケースではない）

## ユーザー指摘（2026-10-25追加）
「過去の勝率は選手情報の1要素でしかない。競走得点と同列にあるべき」

## 理論的含意
- 1着確率を単一要素（勝率のみ、競走得点のみ）で推定するのは不適切
- 複数要素（競走得点・勝率・2連対率・3連対率・脚質・ライン等）を統合すべき
- 各要素の寄与度は実測でしか分からない
- 段階的に要素を追加し、ブライアスコアで寄与を測る（アブレーション実験）

## アブレーション設計（1着確率の要素統合）
| 段階 | 入力要素 | 期待される効果 |
|---|---|---|
| 1 | 競走得点のみ（ソフトマックス） | 能力ベースの基準線 |
| 2 | + 勝率 | 直近の1着率を反映 |
| 3 | + 2連対率・3連対率 | 安定性を反映 |
| 4 | + 脚質・ライン | 展開・連動を反映 |

各段階でブライアスコアを測り、寄与度を確定する。
寄与が負の要素は除外する。

## βスイープ結果（2026-10-25、80レース有効）
| β | n | 1着BS | 3連単BS | 3連単対数損失 |
|---|---|---|---|---|
| 0.02 | 80 | 0.1204 | 0.004733 | 5.2227 |
| 0.05 | 80 | 0.1178 | 0.004725 | 5.0678 |
| 0.10 | 80 | 0.1145 | 0.004712 | 4.8896 |
| 0.15 | 80 | 0.1126 | 0.004705 | 4.8023 |
| 0.20 | 80 | 0.1120 | 0.004707 | 4.7939 |
| 0.30 | 80 | 0.1139 | 0.004744 | 4.9654 |
| 0.50 | 80 | 0.1236 | 0.004937 | 5.7952 |
| 1.00 | 80 | 0.1466 | 0.005665 | 9.0072 |

### 結果の理論的評価
- 3指標とも β=0.15〜0.20 で最小 → 競走得点の最適温度が存在する
- 1着BS: 均等予測0.1224 → 最良0.1120（8.5%改善）。競走得点は1着確率に効く
- 3連単BS: 均等予測0.004739 → 最良0.004705（0.7%改善）。ほぼ均等と同じ
- 3連単対数損失: 4.79〜9.01。モデルの識別力は限定的

### 重要な発見
1着確率の改善（8.5%）に対し、3連単確率の改善（0.7%）が極端に小さい。
1着確率の情報が3連単に伝わっていない。
これはハービル法のIIA仮定の破綻を数値で示す最初の証拠。
ユーザーの「順序不一致」の体感と整合する。

## ユーザー指摘（2026-10-25追加）
「評価に勝率だけを取り入れる必要はなく、ラインや脚質等、
得られる情報全ての中から有効な特徴を探せば良い。観点を絞らない」

## 理論的含意
- 事前に「どの特徴が重要か」を絞るのはドメイン知識バイアス
- JSONにある全特徴を候補として、データから有効性を測るべき
- 単変量（情報量、ROC-AUC）と多変量（ロジスティック回帰、permutation importance）の両方で測る
- 過学習防止: 時系列分割、交差検証、特徴数×10以上のサンプル

## 特徴候補（JSONから抽出可能）
| カテゴリ | 特徴 |
|---|---|
| 能力指標 | 競走得点、勝率、2連対率、3連対率 |
| 脚質 | 脚質（逃/捲/差/マ）、逃/捲/差/マの回数 |
| ペナルティ | S、H、B |
| 直近成績 | 直近着順（1着/2着/3着/着外の回数） |
| 物理 | ギア倍数 |
| 属性 | 年齢、期、地区、級班、枠番 |
| ライン | ライン内位置（先頭/番手/3番手）、ライン規模 |
| 展開 | ライン構成（単騎/2人/3人ライン） |

## 検証B結果（2026-10-25、157レース有効、β=0.15）
| 指標 | 3連単 | 3連複 |
|---|---|---|
| ブライアスコア | 0.004703 | 0.026665 |
| 対数損失 | 4.8549 | 3.1103 |
| 均等予測対数損失 | 5.347 | 3.555 |
| 対数損失改善率 | 9.2% | 12.5% |

### 理論的解釈
- 両方とも均等予測より改善（競走得点に情報あり）
- 改善率は3連複の方が大きい（12.5% vs 9.2%）
- 情報変換効率比 9.2/12.5 = 0.74。ハービル法は26%の情報を順序推定で失う
- ユーザーの「順序不一致」の体感を数値で裏付けた
