# 新設計 テーブル定義（確定版）

本ドキュメントは新設計の7テーブルを定義する。以後の会話では日本語名を使う。
英字名はSQL実装用、日本語名は会話用。

## 全体構成

### 検証側（新設計）

| # | 日本語名 | 英字名 | 単位 | 役割 |
|---|---|---|---|---|
| 0 | 競輪場マスタ | bank_master | 競輪場1件 | バンク特性 |
| 1 | レース結果 | race_results | レース1件 | 着順・払戻 |
| 2 | レース情報 | race_info | レース1件 | 出走表・詳細情報 |
| 2b | レースオッズ | race_odds | 買い目1件 | 全券種オッズ |
| 4 | 想定 | assumptions | 買い目1件 | 全買い目の予測マスタ。投票有無も持つ |
| 5 | 検証 | verification | 買い目1件 | 想定と結果の突合値 |
| 3 | 集計キャッシュ | aggregation_cache | 集計区画1件 | 画面表示用の計算済み値 |

### 実運用側（現状維持・触らない）

| 日本語名 | 英字名 | 役割 |
|---|---|---|
| 実資金投票 | live_bets | 収益ページ専用。検証側と分断 |
| 証拠金 | bankroll_state | 残高管理 |

収益は集計に使っていない。検証側刷新の影響は受けない。

## 0. 競輪場マスタ（bank_master）

**目的**：バンク特性を保持。競輪場はレース個別ではないため独立マスタ。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| id | 競輪場ID | Integer | 主キー | |
| name | 競輪場名 | String(50) | 不可 | 例 佐世保 |
| lap_length_m | 周長 | Float | 可 | 周長(m) |
| home_stretch_length_m | 直線長 | Float | 可 | 直線(ホームストレッチ)長(m) |
| lead_advantage_score | 先行有利度 | Float | 既定 | 0(差し有利)〜1(先行絶対有利) |
| notes | 備考 | Text | 可 | |

## 1. レース結果（race_results）

**目的**：レースの確定結果を保持。払戻金額もここで管理。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| race_id | レースID | TEXT | 不可 | 主キー。oddspark:場:日:番号 形式 |
| actual_result | 実際の着順 | TEXT | 不可 | 例 1-3-2。同着は 7-14=9 |
| payout_odds_3t | 3連単払戻オッズ | REAL | 可 | 的中時の配当倍率 |
| payout_amount_3t | 3連単払戻金額 | REAL | 可 | 100円あたりの払戻金額(円) |
| recorded_at | 記録日時 | TIMESTAMP | 不可 | デフォルト現在時刻 |

## 2. レース情報（race_info）

**目的**：レースの事前情報を保持。予測と検証の入力。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| race_id | レースID | TEXT | 不可 | 主キー |
| venue_name | 開催場名 | TEXT | 不可 | 例 佐世保 |
| race_number | レース番号 | INTEGER | 不可 | 例 4 |
| race_date | 開催日 | DATE | 不可 | |
| post_time | 発走時刻 | TIMESTAMP | 可 | JST |
| grade | グレード | TEXT | 可 | GI/GII/GIII/F1/F2 |
| entries | 出走表 | JSON | 可 | 車番・選手名・直近成績・脚質・ライン |
| details | 詳細情報 | JSON | 可 | 天候・バンク特性・展開予想・ステージ・イベント名・締切時刻・読み取り元 |
| fetched_at | 取得日時 | TIMESTAMP | 不可 | |

## 2b. レースオッズ（race_odds）

**目的**：全券種のオッズを保持。検証の入力。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| race_id | レースID | TEXT | 不可 | 複合主キー |
| bet_type | 券種 | TEXT | 不可 | 2車単/2車複/ワイド/3連単/3連複 |
| combination | 買い目 | TEXT | 不可 | 例 1-2-3 |
| odds_value | オッズ | REAL | 不可 | |
| popularity_rank | 人気順位 | INTEGER | 可 | 既存項目を保持 |
| total_vote_amount | 投票総額 | REAL | 可 | 既存項目を保持 |
| updated_at | 更新日時 | TIMESTAMP | 不可 | |

複合主キー：(race_id, bet_type, combination)

## 4. 想定（assumptions）

**目的**：全買い目の予測マスタ。投票していない買い目もここに存在する(voted=0)。
見送りを別テーブルで持たない代わりに、このテーブルで投票有無を管理する。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| id | 想定ID | INTEGER | 不可 | 主キー(自動採番) |
| race_id | レースID | TEXT | 不可 | どのレースか |
| bet_type | 券種 | TEXT | 不可 | |
| combination | 買い目 | TEXT | 不可 | |
| model_version | 予測モデルバージョン | TEXT | 不可 | 例 v1.0, v2.1 |
| predicted_win_prob | 予想的中率 | REAL | 不可 | 0〜1(補正後) |
| predicted_win_prob_raw | 予想的中率_補正前 | REAL | 可 | 補正前の確率 |
| market_prob | 市場確率 | REAL | 可 | オッズから逆算した確率 |
| predicted_ev | 想定EV | REAL | 不可 | 期待値(%) |
| odds_at_prediction | 予測時オッズ | REAL | 不可 | 予測時のスナップショット |
| final_odds | 締切時オッズ | REAL | 可 | 締切時の確定オッズ |
| kelly_fraction | ケリー比率 | REAL | 可 | フラクショナルケリー後の比率 |
| recommended_stake | 推奨購入額 | REAL | 可 | 推奨金額(円) |
| voted | 投票有無 | INTEGER | 不可 | 0=見送り, 1=投票 |
| stake_amount | 投資額 | REAL | 不可 | 投票していれば金額、見送りなら0 |
| purchased_at | 投票日時 | TIMESTAMP | 可 | voted=1のみ |
| is_skip | 見送り判定 | BOOLEAN | 既定 | |
| skip_reason | 見送り理由 | TEXT | 可 | 例 期待値マイナス |
| is_recommended | 買い示唆 | BOOLEAN | 既定 | 期待値プラスかつ見送り対象でない |
| is_box | BOX | BOOLEAN | 既定 | |
| is_multi_ura | マルチ裏目 | BOOLEAN | 既定 | |
| tags | タグ | JSON | 可 | 会場・脚質・ライン構成・確率帯 |
| created_at | 記録日時 | TIMESTAMP | 不可 | |

一意制約：(race_id, bet_type, combination, model_version)

## 5. 検証（verification）

**目的**：想定とレース結果を突き合わせた評価値。買い目1件単位。
レース内EV順位も保存し、上位K件シミュレーションを高速化する。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| assumption_id | 想定ID | INTEGER | 不可 | 主キー。想定への外部キー |
| race_id | レースID | TEXT | 不可 | |
| bet_type | 券種 | TEXT | 不可 | |
| combination | 買い目 | TEXT | 不可 | |
| model_version | 予測モデルバージョン | TEXT | 不可 | |
| predicted_win_prob | 予想的中率 | REAL | 不可 | 想定から複写 |
| predicted_ev | 想定EV | REAL | 不可 | 想定から複写 |
| actual_odds | 実際のオッズ | REAL | 不可 | レースオッズから確定値 |
| voted | 投票有無 | INTEGER | 不可 | 想定から複写 |
| hit | 的中有無 | INTEGER | 不可 | 1=的中 |
| stake_amount | 投資額 | REAL | 不可 | |
| payout_amount | 払戻額 | REAL | 不可 | 的中時のみ |
| profit | 損益 | REAL | 不可 | 払戻 - 投資 |
| prob_band | 予想的中率帯 | TEXT | 不可 | 集計用の帯区分 |
| odds_band | オッズ帯 | TEXT | 不可 | 集計用の帯区分 |
| ev_band | EV帯 | TEXT | 不可 | 集計用の帯区分 |
| race_rank_by_ev | レース内EV順位 | INTEGER | 不可 | 1=そのレースでEV最高 |
| computed_at | 計算日時 | TIMESTAMP | 不可 | |

外部キー：assumption_id → 想定

## 3. 集計キャッシュ（aggregation_cache）

**目的**：画面表示用の集計済み値。入力(検証)が変わらない限り再計算しない。

| 英字名 | 日本語名 | 型 | NULL可 | 説明 |
|---|---|---|---|---|
| id | キャッシュID | INTEGER | 不可 | 主キー |
| scope | 集計範囲 | TEXT | 不可 | 全期間/期間指定/モデル指定等 |
| section | セクション | TEXT | 不可 | 全体/予想的中率帯/オッズ帯/EV帯/上位K/複合フィルタ |
| params | パラメータ | TEXT | 不可 | JSON。帯区切り・K値・閾値 |
| result | 集計結果 | TEXT | 不可 | JSON。n, hits, 的中率, ROI, 平均EV等 |
| source_hash | 入力ハッシュ | TEXT | 不可 | 入力変更の検知用 |
| computed_at | 計算日時 | TIMESTAMP | 不可 | |

一意制約：(scope, section, params)

## リレーション

1.レース結果 ─┐
              ├─ race_id ─→ 2.レース情報
2b.レースオッズ┘

4.想定 ── id ─→ 5.検証(assumption_id)
           └─ race_id ─→ 1.レース結果、2.レース情報

5.検証 ── 集計 ─→ 3.集計キャッシュ
