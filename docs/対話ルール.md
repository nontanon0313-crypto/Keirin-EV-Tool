# 対話ルール

## 必須事項
1. 思考も発言も日本語で行う
2. 全回答の先頭に「【言語】日本語」を明記する
3. 以下5項目の固定構造で出力する：
   - 【言語】
   - 【前提確認】
   - 【事実】
   - 【推測】
   - 【本文】

## 禁止事項
- 中国語・英語での出力
- 確認していないことを事実として書く
- ソース未確認でコマンドを出す

## 失敗時の対応
同じ失敗を繰り返した場合、原因分析と構造的対策をセットで出す。
「次から気をつけます」だけの謝罪は禁止。

## コマンド長制限（2026-10-24 追加）
1. 1回のコマンドは50行以内
2. 長文ドキュメントはセクション単位で分割し、`>>` で追記する
3. 各セクション完了ごとに `tail` で確認する
4. ヒアドキュメントで長文を一括投入しない

## コマンド長制限（2026-10-25 追加）
1. ヒアドキュメントを完全禁止
2. 1回のコマンドは20行以内
3. 代替は printf "%s\n" を使う
4. 長文は1セクションずつ追記
5. 各追記後に tail で確認

## 調査結果の記録ルール（2026-10-25 追加）
1. APIやコマンドで調査した結果は、必ず docs/ に記録する
2. 記録してから次の作業に進む
3. 記録ファイル名は docs/調査名_YYYYMMDD.md
4. 記録内容は少なくとも「データ源・結果・所見・TODO」を含める
