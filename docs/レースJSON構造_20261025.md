# レースJSON構造 2026-10-25

18231件のレースJSONの構造。モデル分析の入力。

## トップレベル
- jo_code: 場コード（文字列）
- kaisai_bi: 開催日（YYYYMMDD）
- race_no: レース番号
- scraped_at: 取得日時（ISO）
- entry: 出走表・レース情報
- odds: 券種別オッズ
- result: 着順・払戻
- data_quality: 品質フラグ

## entry
- race_name: レース名（例: A級予選）
- grade: グレード（F1等）
- event_title: 開催名
- post_time_iso / close_time_iso: 発走・締切時刻（ISO）
- riders: 出走選手リスト（24キー）
- lines: ライン構成（例: [[4,1],[2,5,7],[3,6]]）
- lines_detail: ライン役割（例: 自在/追込/逃捲）
- narabi_comment: 並びコメント
- url / sp_url: 元ページURL

### riders の24キー
車番・選手名・年齢・期・地区・級班・脚質・競走得点・枠番・
逃・捲・差・マ・S・H・B・ギア倍数・直近着順(dict)・直近着順_raw・
勝率・2連対率・3連対率・コメント・今場所前場所

## odds
- キー: 2車単・2車複・ワイド・3連単・3連複
- 各券種: {bet_type, matrix_count, expected_count, is_complete, missing_count, matrix, bet_code, failed_axes}
- matrix形式: [{1着, 2着, 3着, オッズ}, ...]
- 3連単は210件（7車×6×5）で完全取得
- 他券種は is_complete: false, matrix_count: 0（3連単のみ運用）

## result
- results: 着順リスト
  - {着順, 車番, 選手名, 決まり手_着差, 上り, SB}
- payouts: 払戻リスト
  - {賭式, 払戻金, 人気}

### 注意点
- payouts に組み合わせが無い。results の車番順から導出する
  - 3連単の勝ち組み合わせ = results[0].車番 + "-" + results[1].車番 + "-" + results[2].車番
  - 例: results車番 2,7,5 → 3連単 "2-7-5"
- 払戻金はカンマ付き文字列（例: "9,830円"）→ 数値化必要

## 全期間の均一性
- 2026-01 / 2026-04 / 2026-10 の代表ファイルで全キー一致
- パーサーは1種類で全期間対応可能
